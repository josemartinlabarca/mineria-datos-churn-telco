## Cómo ejecutar los notebooks

1. Abrir el notebook en Google Colab.
2. Guardar el token de Kaggle en los **Secretos de Colab** (🔑) como `KAGGLE_API_TOKEN` y activar el acceso del notebook.
3. Ejecutar **Entorno de ejecución → Reiniciar sesión y ejecutar todo**.

Los datasets se descargan desde Kaggle con `kagglehub`. Ningún token ni credencial se guarda en este repositorio.
